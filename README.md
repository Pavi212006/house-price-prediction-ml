# House Price Prediction — Machine Learning Portfolio Demo

A reproducible regression project that compares a simple Linear Regression baseline with a Random Forest model. It includes a small Streamlit interface for exploring model predictions after training.

> **Project context:** This is a personal portfolio reconstruction/learning demo based on the house-price prediction topic. It is not the original source code from WayEva Innovations, and it does not verify or claim what was submitted during any internship. Keep the internship and project descriptions on a CV aligned with the work you personally completed.

## What it demonstrates

- Loading a documented, public regression dataset
- Separating training, validation, and test data
- Comparing a baseline model with a tree-based model
- Selecting a model using validation RMSE
- Reporting MAE, RMSE, and R² on a held-out test set
- Saving and loading a trained model with `joblib`
- Building a small interactive front end with Streamlit
- Reproducibility through fixed random seeds

## Dataset and limitations

The project uses the **California Housing dataset** provided by scikit-learn ([official dataset documentation](https://scikit-learn.org/stable/modules/generated/sklearn.datasets.fetch_california_housing.html)). It contains 20,640 records with eight numeric features and a target called `MedHouseVal`, measured in units of **$100,000**. The data is census-derived at the California block-group level, not individual home listings, and was derived from the 1990 U.S. Census ([dataset description](https://github.com/scikit-learn/scikit-learn/blob/main/sklearn/datasets/descr/california_housing.rst)). It is a standard educational benchmark, not a current listing-price feed. The dataset reflects a historical period and has geographic and dataset-specific limitations. The model is for learning and demonstration only, not financial decisions, property valuation, or real-estate advice.

The training script fetches the dataset the first time it is run, so initial training requires an internet connection. scikit-learn caches the dataset for later runs.

## Setup

Python 3.10 or newer is recommended.

### 1. Create and activate a virtual environment

Windows PowerShell:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

If script activation is blocked by your system policy, use Command Prompt activation instead:

```bat
.venv\Scripts\activate.bat
```

macOS/Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 2. Install dependencies

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 3. Train and evaluate models

```bash
python train_model.py
```

This downloads/caches the dataset if needed, compares Linear Regression and Random Forest using validation data, refits the selected model on the training-plus-validation data, evaluates it on the held-out test data, and saves the model and metadata in `artifacts/`.

### 4. Run the interactive app

```bash
streamlit run app.py
```

Open the local URL shown by Streamlit. The app requires the model artifacts generated by Step 3.

### 5. Run tests

```bash
python -m unittest discover -s tests -v
```

The unit tests use small in-memory values and do not download the housing dataset.

## Understanding the metrics

- **MAE (Mean Absolute Error):** average absolute prediction error, in the target's $100,000 units in the raw model output. The app converts predictions to dollars for display.
- **RMSE (Root Mean Squared Error):** similar to MAE but penalizes larger errors more strongly.
- **R²:** compares the model with predicting the test-set mean; values closer to 1 generally indicate a better fit, while negative values can occur.

Do not report performance numbers in a CV or interview until you have run the training script and can reproduce the metrics stored in `artifacts/metrics.json`.

## Suggested manual checks

1. Train the model and confirm that `artifacts/model.joblib` and `artifacts/metrics.json` are created.
2. Run the app and try values within the displayed feature ranges.
3. Check that the displayed price is positive and in dollars, while the saved metrics retain the dataset's original target units.
4. Run the test command.
