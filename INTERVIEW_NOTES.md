# Interview Notes: House Price Prediction Demo

## A 30-second explanation

"This is a regression project using the California Housing benchmark dataset. I compare Linear Regression as a simple baseline with Random Forest as a nonlinear model. I split the dataset into training, validation, and test sets. I select a model based on validation RMSE, then evaluate it on a separate held-out test set using MAE, RMSE, and R-squared. I save the chosen pipeline and provide a small Streamlit interface to try predictions. The dataset is historical and the app is an educational demonstration, not a current property valuation tool."

## Questions you should be able to answer

### Is this classification or regression?
It is regression because the target is a numeric value (median house value), rather than a category such as high/low.

### What are the input features?
The benchmark uses median income, median house age, average rooms, average bedrooms, population, average occupancy, latitude, and longitude at the census block-group level.

### Why compare Linear Regression and Random Forest?
Linear Regression is a simple baseline that models a linear relationship. Random Forest combines many decision trees and can model nonlinear patterns. We compare the models on validation data rather than assuming a more complex model is automatically better.

### Why have train, validation, and test sets?
Training data fits model parameters. Validation data helps choose between candidate models. The test set is held aside for a final, less-biased estimate of performance after selection.

### What is MAE?
Mean Absolute Error is the average absolute difference between predictions and actual values. Lower is better. The original target is measured in units of $100,000, so a raw MAE of 0.3 corresponds to about $30,000 in the dataset's target scale.

### What is RMSE?
Root Mean Squared Error squares errors before averaging and taking the square root. It penalizes large mistakes more strongly than MAE. Lower is generally better for the same dataset.

### What is R-squared?
R-squared compares the model with a simple mean-target baseline. Values closer to 1 generally indicate a stronger fit; a negative value can occur when the model performs worse than that baseline on the evaluation set.

### Why use a Pipeline?
A pipeline keeps preprocessing and the model together. It helps ensure that imputation and scaling are fitted on training data and then applied consistently to validation, test, and new input data.

### Why save with joblib?
It serializes the trained scikit-learn pipeline so the app can load it for inference without retraining on each page load. Load only model files you trust.

### What are the limitations?
The data comes from a historical period, covers California, and describes census block groups rather than individual homes or current listings. It may not generalize to other regions or current markets. Good test metrics on this benchmark do not prove that it can accurately price a specific property today.
